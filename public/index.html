AI agents buy on credit. The desk still gets every dollar, and proves it.

Every other agent-payments project teaches agents to hear "no". TAB says "yes, pay later". Northwind Data sells to buyer agents on terms: Claude runs the agents and reads the messy text, code decides every price, limit, credit and collection, and Metal, Visa via Airi, Airwallex and T:0 move and record the money.

This is one live run, , played back event by event. Each Metal transaction links to the public testnet explorer; Airwallex and T:0 ids come from private sandboxes that the desk's checker read back after the run.

Labelled, not hidden

  • Globex's and Initech's books are a stand-in; Acme's are real T:0 sandbox records.
  • Airwallex deposits are sandbox simulations; quotes, conversions and card payments are real sandbox calls.
  • Due dates are compressed to minutes so the run fits a video.
  • Stale units are set by the script, standing in for delivery QA.
