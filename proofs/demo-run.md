# Full demo run (2026-11-11, run `rmwbpgwbj`)

`LIVE_VIC=1 npx tsx scripts/demo-run.ts` plays every scene into `data/desk-demo.json`; the demo screen (`npm run screen`) streams them and `npm run replay` turns the run into the no-login replay page (`docs/index.html`). Live: Metal testnet, Claude (`claude-opus-5-5`: CFO policy compiler, two buyer agents, dispute reader), Visa Intelligent Commerce via Airi (one passkey approval), Airwallex sandbox, T:0 sandbox. **26/26 checks pass.**

What is labelled rather than live:
- **Whose books.** Every buyer's history is read from the T:0 sandbox. Acme is mapped to an existing sandbox customer, "Zephyr Metrics AB". Initech's history (a $60 invoice paid 5 days late, a $400 invoice overdue since Oct 18) and Globex (a customer with no invoices; its $80 from run `rmwavgb3a` recorded as a payment applied to no invoice) were written into the sandbox by us with `scripts/t0-seed-buyers.ts`. So were the three $150 Slack bills the payout finds.
- **Airwallex deposits** are sandbox simulations (the sandbox cannot receive stablecoins); quotes, conversions, card payments and the transfer are real sandbox calls. The transfer is moved to PAID with the sandbox simulation call, to a beneficiary with sandbox bank details.
- **Due dates are compressed**: Acme's statement mandate opens about 70 s after issue and closes 5 min later; Globex's 7-day card tab is captured seconds after its credit note.
- **Stale units are set by the script** (Acme: 10% of the disputed order flagged by delivery QA; Globex: one 1,000-row batch). The model reads the email; credits come from the QA count, never from the email's "all units".
- **Globex's card is the same Airi test card** Acme used on 2026-11-09 (one card is enrolled).
- **Initech** has no Metal account or mandate (placeholder address); it shows the books and orders for terms it is not offered being refused.
- **Acme's testnet balance** was $328.06 (above the faucet's 100 USDZ ceiling via `scripts/top-up-buyer.ts`, helper pulls `0x00b62151…da14` and `0x27dbbe53…0d1e`), so its credit limit is capped by its balance rather than the CFO's first $350 cap.
- **The buyers' owner keys** that bind mandates are key files run by the demo script, standing in for each buyer's human. The CFO's policy key is likewise a key file the script signs with.
